# 深度学习使用相关（算子增强 + 新增相似度算子）

> 本轮把「深度学习」在算子链里的可用性补齐：既有「深度学习推理」算子更好用，
> 并新增「深度学习相似度」算子。全部自研 / 开源可商用（ONNX Runtime MIT、模型用户自备）。

---

## 一、算子库中的深度学习算子一览

| 算子 | 用途 | 模型要求 |
|---|---|---|
| **深度学习推理**（增强） | 图像分类 / 目标检测 | 分类：`[1,3,S,S]` → `[1,C]` logits；检测：YOLOv5/YOLOv8 导出格式 |
| **深度学习相似度**（新增） | 与参考图比相似度（查重 / 好件坏件比对 / 小样本同类判定） | 特征模型 `[1,3,S,S]` → `[1,D]` 或 `[D]` 特征向量 |

两算子都支持：模型文件热重载（换模型不用重启）、失败防御（任何异常返回原图+摘要，不炸链）。

---

## 二、深度学习推理算子增强（本轮）

1. **输入边长 0 = 自动读取模型输入尺寸**（默认）：
   - 训练页导出的分类模型、YOLO 系模型等，只要输入是正方形 `[1,3,H,H]`，
     加载后**无需手填边长**，直接从模型元数据读取；
   - 模型输入非正方形（如 `[1,3,800,600]`）时给出明确提示，不再静默维度报错。
2. **新增参数「显示前N类」**（分类模式，默认 5，可调 1~10）：
   - 结果图上标注前几个类别及概率，不想要那么多就调小。

参数区（视觉页「深度学习推理」专用行）用法不变：选 .onnx + 选标签 .txt + 清除模型。

## 三、深度学习相似度算子（新增）

### 用途场景
- **图像查重**：同一物料 / 同一界面 / 同一工件外观比对；
- **缺陷前后对比**：好件设参考，来件相似度低于阈值即判「不匹配」；
- **小样本分类的补充用法**：训练页导出的分类模型（logits 当特征）可直接当特征模型，
  同类图特征接近、异类图差异大。

### 使用步骤（视觉页）
1. 把「深度学习相似度」加入算子链（参数区出现专用行）；
2. **选择特征模型(.onnx)…**：选一个特征提取模型；
   - 推荐训练页导出的分类模型（开箱即用，零额外模型成本）；
   - 追求更精细相似度可换专用特征模型（MobileNet 倒数第二层、ArcFace 等，注意可商用许可）；
3. **设当前主图为参考**：先把参考图（好件 / 标准图）设为当前主图，点此按钮提取特征；
   - **清除参考**：换参考图时先清除再重设；
4. 运行链：每张输入图与参考图比余弦相似度，图上左下角标注
   「相似度 xx% — 匹配（绿）/ 不匹配（红）」，摘要同显。

### 参数
| 参数 | 默认 | 说明 |
|---|---|---|
| 相似度阈值 | 70% | 低于判定「不匹配」；误报多调高、漏报多调低 |
| 输入边长 | 0 | 0 = 自动读取特征模型输入尺寸；失败时手动填 |

### 特征模型约定
- 输入 `[1,3,H,W]`（RGB 0~1，H=W 正方形），边长自动读取或手动指定；
- 输出 `[1,D]` 或 `[D]`（D ≥ 2），内部 L2 归一化后比余弦（相似度钳到 0~1）。

  - 深度学习推理：参数 5 个（含显示前N类）；输入边长 0 自动读取路径防御正确（不崩、返回 Mat、摘要完整）；

## 五、Windows 实机复测路径（Linux 冒烟环境无 onnxruntime 原生库，真推理需 Windows 换包）

1. 打开 `VisionToolDemo.sln`，`dotnet build -c Release`（需 net8 SDK）。
2. **推理自动尺寸**：视觉页添加「深度学习推理」→ 选 `test_models\mini_classifier.onnx` +
   标签 → 输入边长保持 **0** → 打开一张图跑链：应自动按 224 推理并正确标注类别。
3. **相似度算子**：添加「深度学习相似度」→ 选同一模型（logits 当特征）→
   打开一张红图 → 点「设当前主图为参考」→ 打开蓝图跑链：应显示「相似度低 — 不匹配」；
   再打开同图跑链：应显示「相似度 99%+ — 匹配」。
4. 训练页导出模型后，两个算子都可直接加载（分类模型当特征模型时语义为近似相似度）。
