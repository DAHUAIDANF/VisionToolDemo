# 实时目标跟踪（视频 / 摄像头）使用说明

本次为 VisionToolDemo 新增 **目标跟踪** 能力：打开视频文件或摄像头，在画面上拖框框住目标，即可逐帧自动跟踪并实时画框。

## 一、新增内容

| 文件 | 作用 |
|---|---|
| `Vision/Tasks/TrackTask.cs` | 「目标跟踪」算子（OpenCV KCF / CSRT / MIL 追踪器），加入算子链后可与批量、记录等联动 |
| `Wpf/TrackPreviewWindow.xaml(.cs)` | 实时跟踪预览窗口：打开视频/摄像头 → 拖框选目标 → 逐帧跟踪画框 |
| `Wpf/Views/PipelinePage.xaml(.cs)` | 视觉页集成：工具条新增「实时跟踪…」；「目标跟踪」算子参数区新增「框选目标/重置」专用行 |

## 二、两种用法

### 用法 A：实时预览窗口（视频 / 摄像头，最直观）

1. 视觉页顶部工具条点 **「实时跟踪…」**，打开实时跟踪窗口；
2. 点 **「打开视频…」**（mp4/avi/mov/mkv/wmv/flv/m4v/mpg/ts）或 **「打开摄像头…」**（输入设备号 0~5，0 通常是默认摄像头）；
3. 画面出来后**点「暂停」**，在画面上**按住鼠标左键拖一个框框住目标**（松开即自动初始化追踪器）；
4. 点 **「继续」** 恢复播放，此后每一帧自动跟踪目标并画框：
   - **绿框** = 跟踪成功（底部状态栏实时显示坐标、尺寸、帧数与 FPS）；
   - **红框** = 目标丢失（保留上一帧位置，提示"目标丢失"）。

工具栏还提供 **追踪器类型**（KCF 快/CSRT 准/MIL 鲁棒，换类型需重新框选）与 **重置跟踪**。

### 用法 B：目标跟踪算子（进算子链，可批量/记录/导出）

1. 左侧算子库把 **「目标跟踪」** 加入算子链；
2. 参数区出现专用行：先在**主图**上用鼠标拖框框住目标 → 点 **「框选目标」**；
3. 之后每次执行（批量图片 / 逐帧处理）都会自动跟踪并画框，摘要输出目标坐标、尺寸与帧数。

算子参数：
- **追踪器**：0 KCF（默认，快、通用）/ 1 CSRT（更准更稳，稍慢）/ 2 MIL（对光照形变更鲁棒）；
- **丢失处理**：0 提示目标丢失并保留上一位置画红框 / 1 自动用上一帧位置重新初始化。

> 提示：想让**实时预览窗口**的跟踪结果同步进算子链，先在视觉页把「目标跟踪」算子加链并框选目标，再打开实时跟踪窗口即可共用同一追踪目标。

## 三、已实测 / 待实机验证

| 项目 | 状态 |
|---|---|
| KCF / CSRT / MIL 追踪器初始化与逐帧 Update（合成运动目标，目标框正确跟随） | ✅ 已实测（Linux 反射运行） |
| 「目标跟踪」算子注册、参数定义、未框选防御、框选初始化、运动追踪摘要 | ✅ 冒烟 101/101 全绿 |
| 视频文件逐帧播放与拖框跟踪（TrackPreviewWindow） | ⏳ 需 Windows 实机（Linux 无 WPF/图形） |
| 摄像头实时取流与跟踪 | ⏳ 需 Windows 实机（需接入真实摄像头） |

**Windows 实机复测路径**：编译运行 → 视觉页 → 实时跟踪… → 打开一个含运动物体的视频 → 暂停 → 拖框框住物体 → 继续 → 观察绿框是否跟随、丢失时是否红框提示；再试「打开摄像头…」指向本机摄像头重复上述步骤。

## 四、备注

- 追踪器均为 OpenCV 内置算法（KCF/CSRT/MIL），不依赖模型文件，开箱即用；
- 目标丢失后如需重新框选：预览窗口点「重置跟踪」，或视觉页算子行点「重置」；
- 换追踪器类型会自动重建追踪器（算子内用上一次目标框重新初始化；预览窗口需重新框选）。
