# VisionToolDemo — 视觉检测工作台（WPF）

基于 C# / .NET 8 + WPF 的桌面视觉检测与自动化工作台。支持视觉流水线编排、几何测量、OCR 文字识别、深度学习训练与推理、ROI 框选、实时目标追踪与浏览器自动化等能力，适用于工业视觉检测、图像处理教学与自动化流程演示。

## 功能特性

- **视觉流水线**：算子链 / 节点系统，支持流程编排、条件分支、循环、变量与表达式
- **算子库**：
  - 图像预处理：灰度化、二值化/阈值、滤波、形态学、缩放旋转、涂抹
  - 特征提取：边缘/轮廓、卡尺、模板匹配
  - 几何测量：距离、角度（三点角度/两线夹角）、圆、线、面积、周长、拟合、偏心、同心、平行、垂直、椭圆等
  - 识别：条码/二维码识别（多码型）、OCR 文字识别（Tesseract，支持多行、多引擎）
  - 深度学习：分类 / 目标检测 / 相似度比对推理
- **深度学习训练**：
  - 训练页：数据标注（类 labelimg 式可视化编辑、标签池）、数据增强、YOLOv5 训练、混淆矩阵、导出 ONNX
  - 推理：滑窗多人/多目标识别、人脸检测增强（YuNet 优先 + Haar 回退）、ROI 限定识别、结果叠加标签与置信度
- **ROI 框选**：原图/结果图同步框选，支持任意尺寸图片，框选位置与鼠标实际位置一致
- **自动化**：工作流节点（打开文件/浏览器、鼠标移动点击、弹窗提示、条件分支、循环控制），支持随机偏移模拟人工操作
- **实时追踪**：摄像头/视频实时目标追踪，支持人脸追踪选项
- **界面**：多主题切换（深蓝灰 / 深墨绿 / 深紫罗兰 / 暖橙红 / 亮色浅色），统一跟随主题

## 技术栈

| 类别 | 选型 |
|---|---|
| 语言/框架 | C#，.NET 8（net8.0-windows），WPF + MVVM |
| 图像处理 | OpenCvSharp（OpenCV 4） |
| OCR | Tesseract（中文/英文语言包） |
| 深度学习 | ONNX Runtime（YOLOv5 等模型），YuNet / Haar 人脸检测 |
| 测试 | xUnit，含 WIDER 人脸增强、多目标识别、节点覆盖等回归测试 |

## 快速开始

1. 环境要求：Windows 10/11，.NET 8 SDK
2. 打开 `VisionToolDemo.slnx`，还原 NuGet 包
3. 直接运行（F5）
4. 运行单元测试：

```bash
dotnet test VisionToolDemo.Tests/VisionToolDemo.Tests.csproj
```
